# Docs, Intent, and Research Pattern

Status: Active
Date: 2026-04-09
Owner: GitGraph Lab

## Core Rule

Important architecture claims must be traceable to intent, research, decision, and verification.

## Lifecycle

1. Intent: goals, constraints, success criteria.
2. Research: options, tradeoffs, risks, source-backed claims.
3. Decision: ADR or system doc update with chosen path.
4. Implementation: change in correct layer boundary.
5. Verification: tests, gates, perf evidence, and residual risk.

Short form:

**No decision without research. No confidence without verification.**

## Quality Rules

1. Prefer primary sources for external claims.
2. Distinguish evidence from inference.
3. Keep uncertainty explicit when verification is incomplete.
4. Link ADRs and system docs when one depends on another.
